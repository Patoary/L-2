1.PostgreSQL হলো একটি open-source relational database management system (RDBMS)। এটি database-এর মধ্যে data সংরক্ষণ, পরিবর্তন, খোঁজা এবং পরিচালনা করার জন্য ব্যবহার করা হয়।

2.Database schema হলো একটি database-এর ভিতরের একটি logical structure যেখানে tables, views, functions ইত্যাদি রাখা যায়।
schema ব্যবহার করে database-এর objects সুন্দরভাবে organize করে রাখা যায় ।

3.Primary Key table-এর একটি column যার value প্রতিটি row-কে uniquely identify করে।
Foreign Key একটি column যা অন্য table-এর Primary Key-কে reference করে।

4.VARCHAR এবং CHAR PostgreSQL-এ text/string data রাখার জন্য ব্যবহার হয়। VARCHAR variable-length text রাখে।CHAR fixed-length text রাখে।

5.WHERE clause ব্যবহার করে table থেকে নির্দিষ্ট শর্ত অনুযায়ী data filter করা হয়।
